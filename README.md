# Willes Bilbärgning – Följesedlar

Enkel webbapp för att skriva följesedlar i mobilen, som underlag till fakturering i Fortnox.

- Snabbval för utfört arbete och tid (går att ändra i appen)
- Timpris med bärgningsbil / arbetstid, priset räknas ut automatiskt
- Automatisk numrering, kodlås och Excel-export av ej fakturerade

Allt sparas lokalt i telefonens webbläsare. Öppna appen och välj "Lägg till på hemskärmen".
